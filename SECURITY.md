# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately by email to **328575328@qq.com**.
Do not open public issues for security problems.

Include:
- A description of the vulnerability and the affected component/version
- Steps to reproduce or a proof-of-concept
- Any suggested mitigation

We aim to acknowledge reports within 72 hours and will coordinate a fix and
disclosure timeline with you.

## Supported Versions

Only the latest release on the default branch is supported.

## Responsible Use

Prism is a network debugging / interception tool intended for use on networks
and devices you own or are explicitly authorized to test. The Android root
certificate installation and privilege-escalation helpers are provided solely
for debugging your own devices. Do not use this software to intercept traffic
without authorization.
